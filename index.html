Embedded

A lightweight native library that runs in your process, in memory or durably with bundled SQLite.

02

Immutable

Transactions produce new database values. Existing snapshots remain valid and queryable.

03

Declarative

Datalog queries, rules, pull expressions, entities, indexes, and historical views.

Query data, not tables

Ask for what you need.

VevDB follows Datomic’s data model and familiar API. Facts accumulate, database snapshots are ordinary values, and queries stay independent of storage layout.

Clojure
(require '[vev.core :as d])

(def conn (d/create-conn))

(d/transact conn
  [{:db/id 1 :person/name "Ada"}
   {:db/id 2 :person/name "Grace"}])

(d/q '[:find ?name
       :where [?e :person/name ?name]]
     (d/db conn))
